# MedCare Hospital

A full-stack hospital appointment booking system. Patients can view doctors and book consultations online, and hospital staff can manage appointments through a secure admin dashboard.

## Features

- Browse medical services and doctors
- Book appointments by selecting a doctor, date and time
- Secure admin login
- Admin dashboard with live appointment details (patient, doctor, date, time, status)

## Tech Stack

- **Frontend:** React, Vite
- **Backend:** Node.js, Express
- **Database:** MongoDB

## Getting Started

**Prerequisites:** Node.js and MongoDB

```bash
# Start the backend
cd backend
npm install
node server.js

# Start the frontend (in a new terminal)
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
